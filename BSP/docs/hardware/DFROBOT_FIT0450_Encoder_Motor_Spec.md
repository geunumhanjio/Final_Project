# DFROBOT 엔코더 TT 모터 (FIT0450)

Micro DC Gearmotor with Quadrature Encoder

## 1. 개요

인코더가 장착된 마이크로 DC 기어모터이다.
120:1 기어박스와 한 회전에 1920 펄스를 출력하는 quadrature encoder를 장착하고 있으며,
금속 출력 샤프트를 갖추고 있어 로봇 프로젝트에 적합하다.

## 2. 모터 사양

| 항목 | 값 |
|------|-----|
| 기어비 (Gear ratio) | 120:1 |
| 무부하 속도 @ 6V | 160 RPM |
| 무부하 속도 @ 3V | 60 RPM |
| 무부하 전류 @ 6V | 0.17 A |
| 무부하 전류 @ 3V | 0.14 A |
| 최대 스톨 전류 | 2.8 A |
| 최대 스톨 토크 | 0.8 kgf·cm |
| 정격 토크 | 0.2 kgf·cm |
| 모터 동작 전압 | 3 ~ 7.5 V (정격 6V) |

## 3. 엔코더 사양

| 항목 | 값 |
|------|-----|
| 엔코더 동작 전압 | 4.5 ~ 7.5 V |
| 엔코더 타입 | Quadrature (A상 + B상) |
| PPR (Pulses Per Revolution) | 480 (출력 축 기준) |
| 4체배 분해능 (x4) | 1920 counts/revolution |

> **PPR 해석:** 사양서에 "한 회전에 1920 펄스"로 표기되어 있는데, 이는 4체배(x4) 적용 후 값이다.
> 엔코더 자체의 PPR은 480이며, STM32 TI12 모드(양쪽 에지 카운트)에서 480 x 4 = 1920 counts/revolution이 된다.

## 4. 일반 사양

| 항목 | 값 |
|------|-----|
| 동작 온도 | -10 ~ +60 ℃ |
| 무게 | 50 g |

## 5. 바퀴 정보 (실측 필요)

오도메트리 계산에 필요한 바퀴/로봇 치수이다. 실측 후 아래 값을 기입한다.

| 항목 | 값 | 비고 |
|------|-----|------|
| 바퀴 지름 | _____ mm | 타이어 포함 외경 직접 측정 |
| 바퀴 둘레 | _____ mm | π × 바퀴 지름 |
| 휠 베이스 (wheel base) | _____ mm | 좌우 바퀴 접지점 간 거리 |

### 오도메트리 변환 공식

```
이동 거리(mm) = (encoder_counts / 1920) × 바퀴 둘레(mm)
선속도(mm/s)  = 이동 거리(mm) / 샘플링 주기(s)
각속도(rad/s) = (v_right - v_left) / wheel_base
```
