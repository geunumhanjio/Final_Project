## 🚫 20W급 단일 보조배터리 동시 출력 불가 사유

현재 스펙(Max 20W~22.5W)의 보조배터리는 **두 포트를 동시에 사용하여 서로 다른 전압(예: 5V 라즈베리파이, 9V/12V 모터 드라이버)을 출력하는 것이 구조적으로 불가능**합니다.

* **승압 회로(DC-DC Boost) 단일화:** 대부분의 보급형 보조배터리는 내부에 전압을 높이는 회로가 1개뿐입니다.
* **보호 회로 작동 (5V 하향 고정):** 한 포트에서 9V/12V 고속 충전을 사용 중이더라도, 다른 포트에 일반 5V 기기(라즈베리파이 등)가 연결되면 **안전을 위해 모든 포트의 출력이 강제로 5V로 하향 고정**됩니다.
* **결과:** 라즈베리파이와 모터(디코이 케이블)를 동시에 꽂는 순간, 모터로 가던 9V/12V가 5V로 떨어져 작동이 불가능해집니다.

**해결 방안:**
1. **보조배터리 2개 분리 사용 (가장 안전/추천):** 5V용(라즈베리파이)과 9V/12V 트리거 케이블용(모터) 배터리를 각각 따로 구성.
2. **고출력(65W 이상) 배터리 1개 + 강압 모듈:** 배터리에서 12V만 뽑아 모터에 주고, 강압 모듈(Buck Converter)을 거쳐 5V로 낮춰 라즈베리파이에 공급.
3. **독립 출력(Dual Independent Output) 보조배터리 구매:** 포트별 회로가 분리된 고가형 배터리 사용.

## 🔎 독립 출력(동시 다중 전압) 보조배터리 판별법

상품 상세 페이지만 보고 "포트 1은 5V, 포트 2는 9V/12V"를 동시에 쏴줄 수 있는 배터리인지 구별하는 방법입니다.

1. **동시 출력/고속 충전 지원 안내 문구 확인 (가장 확실함)**
   * **❌ 불가 모델:** "동시 충전 시 일반 충전(5V)으로 변환됩니다", "동시 충전 시 고속 충전 미지원"
   * **✅ 가능 모델:** "동시 충전 시에도 고속 충전 유지", "듀얼 독립 고속 충전 지원"
2. **출력(Output) 스펙 표의 합계 방식 확인**
   * **❌ 불가 모델:** 합계(Total)가 `5V / 3A (15W Max)`처럼 특정 전압으로 묶여 있음.
   * **✅ 가능 모델:** 합계(Total)가 `65W + 18W (Max 83W)`처럼 **포트별 전력(W)이 분리 합산**되어 있음.
3. **용량 및 가격대**
   * 최소 **65W ~ 100W 이상의 노트북급 고출력 배터리**여야 구조적으로 독립 승압 회로가 2개 이상 들어갈 공간과 단가가 나옵니다.
