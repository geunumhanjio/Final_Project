# 2026-02-23 개발일지

## [Review] SoftStop vs EmergencyStop 동작 비교

| | SoftStop (타임아웃) | EmergencyStop |
|---|---|---|
| IN1/IN2 | 둘 다 LOW (coast) | 둘 다 HIGH (brake) |
| 트리거 | 통신 500ms 끊김 | `CMD_ESTOP` 수신 |
| 이후 명령 | 바로 수신 가능 | `CMD_RELEASE` 필요 |

---

## [Review] ESTOP 트리거 경로 분석

현재 `Motor_EmergencyStop()` 호출 경로는 **단 하나** — RPi에서 `CMD_ESTOP (0x03)` 패킷 수신 시.
STM32 자체 감지(센서 이상, 하드웨어 인터럽트 등)는 미구현.

---

## [Feat] 수신 패킷 디버그 출력 추가

`uart_protocol.c`의 `Protocol_Dispatch()`에 조건부 컴파일 블록 추가, `Makefile`에 `-DDEBUG_PACKET` 플래그 추가.

```
[PKT] CMD=0x01 LEN=4 D[0]=0xE8 D[1]=0x03 D[2]=0xE8 D[3]=0x03
```

릴리즈 시 Makefile에서 `-DDEBUG_PACKET` 제거하면 빌드에서 완전히 제외됨.
