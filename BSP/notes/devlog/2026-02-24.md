## [Feat] 엔코더 속도 계산 함수 추가 (`Encoder_GetSpeed`)

`encoder.c`에 `Encoder_GetSpeed(MotorSide side)` 추가.
10ms 주기로 tick 변화량을 측정해 mm/s 단위로 반환. PPR=1920, 바퀴 둘레는 `WHEEL_CIRCUMFERENCE_MM` 매크로로 분리.

```
speed (mm/s) = (delta_tick / 1920) × 바퀴둘레(mm) / 0.01s
```

## [Feat] 모터 제어 PID 기반으로 전환 (`Motor_PID_Update`)

| | Before (Open-loop) | After (Closed-loop) |

| 피드백 | 없음 | 엔코더 실제 속도 |
| 파일 변경 | — | `motor_control.c` -121 / +86 라인 |
